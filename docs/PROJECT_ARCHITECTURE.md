# Документация Проекта (Admiral Laravel)

## 1. Общее Описание
Проект представляет собой корпоративный веб-сайт с интегрированной панелью администратора и функционалом лидогенерации. Основная сфера деятельности (судя по контенту) — финансовые услуги, работа с задолженностями, юридическая помощь.

Проект построен на современном стеке технологий, использующем последние версии Laravel, Filament и Tailwind CSS.

## 2. Технологический Стек

### Бэкенд (Backend)
- **Язык**: PHP 8.2+
- **Фреймворк**: Laravel 12.0 (Latest)
- **Админ-панель**: Filament 5.1
- **База данных**: Поддержка стандартных реляционных БД (MySQL/PostgreSQL/SQLite) через Eloquent ORM.

### Фронтенд (Frontend)
- **Сборщик**: Vite 7.0
- **Стили**: Tailwind CSS 4.0 (с плагином `@tailwindcss/vite`)
- **Шаблонизатор**: Blade (стандартный для Laravel)
- **JavaScript**: Vanilla JS + Axios для API запросов

### Инструменты Разработки
- **Spatie Laravel Sitemap**: Для генерации карты сайта.
- **Laravel Pint**: Для форматирования кода (Code Style).
- **Pest/PHPUnit**: Для тестирования.

## 3. Архитектура Проекта

### Структура Директорий
Ключевые директории проекта:

- `app/`: Основная логика приложения.
    - `Filament/`: Ресурсы и страницы панели администратора.
    - `Http/Controllers/`: Контроллеры для обработки веб-запросов и API.
    - `Models/`: Eloquent модели (ORM) для работы с БД.
    - `Services/`: Сервисные классы (бизнес-логика).
- `database/migrations/`: Миграции базы данных (версионирование схемы БД).
- `resources/`: Фронтенд-ресурсы.
    - `views/`: Blade шаблоны страниц.
    - `css/`, `js/`: Исходные файлы стилей и скриптов.
- `routes/`: Описание маршрутов (`web.php`).
- `public/`: Публичная директория (точка входа веб-сервера).

### База Данных (Основные Сущности)
Система управляет следующими ключевыми сущностями:

1.  **CompanySetting (`company_settings`)**: Хранит глобальные настройки сайта (SEO заголовки, лицензии, график работы, реквизиты).
2.  **Lead (`leads`)**: Заявки от клиентов с форм на сайте.
3.  **Employee (`employees`)**: Информация о сотрудниках (используется для отображения команды или API поиска).
4.  **Review (`reviews`)**: Отзывы клиентов (с поддержкой модерации через поле `is_visible`).
5.  **Faq (`faqs`)**: Часто задаваемые вопросы (для блока FAQ на главной).
6.  **Phone (`phones`)**: База телефонных номеров (вероятно, для валидации или черных/белых списков).
7.  **User (`users`)**: Пользователи системы (администраторы).

### Маршрутизация и Контроллеры
Основные маршруты определены в `routes/web.php`:

*   **Публичные страницы**:
    *   `GET /` -> `HomeController@index` (Главная страница с отзывами и FAQ).
    *   `GET /about`, `/contact`, `/requisites` -> Статические страницы (Blade views).
    *   `GET /legal/*` -> Юридические документы (Privacy, Terms и т.д.).
*   **Функционал**:
    *   `POST /leads` -> `LeadController@store` (Прием заявок с ограничением `throttle:10,1`).
    *   `GET /sitemap.xml` -> Динамическая генерация через `SitemapService`.
    *   `GET /robots.txt` -> Динамическая генерация.
*   **API (Внутреннее)**:
    *   `GET /api/employees` -> `Api\EmployeeController@search` (Поиск сотрудников).
    *   `GET /api/phones/check` -> `Api\PhoneCheckController@check` (Проверка телефона).

## 4. Особенности Реализации

### 1. Управление Контентом
Контент сайта (отзывы, вопросы, сотрудники) управляется через **Filament Admin Panel**. Это позволяет менеджерам редактировать сайт без вмешательства разработчиков.
*   *Пример*: `HomeController` получает только видимые (`is_visible=true`) отзывы, отсортированные по дате.
*   *Fallback*: В коде присутствует механизм "заглушек". Если в БД нет отзывов или вопросов, контроллер отдает заранее заготовленные данные (удобно для разработки).

### 2. SEO Оптимизация
*   Внедрена таблица `company_settings` с полями для SEO.
*   `SitemapService` автоматически строит карту сайта на основе конфигурации маршрутов.
*   Генерация `robots.txt` на лету с ссылкой на актуальный sitemap.

### 3. Фронтенд Архитектура
Используется **Tailwind CSS 4.0**, что обеспечивает современный подход к стилизации без громоздких CSS файлов. Сборка осуществляется через **Vite**, что дает высокую производительность при разработке (HMR) и оптимизированные ассеты в продакшене.

## 5. Запуск для Разработки (Local Development)

Для запуска проекта локально необходимо два терминала:

1.  **Backend (Laravel)**:
    Запускает PHP сервер.
    ```bash
    php artisan serve
    ```
    Сайт будет доступен по адресу: `http://127.0.0.1:8000`

2.  **Frontend (Vite)**:
    Собирает стили и скрипты в реальном времени (Hot Module Replacement).
    ```bash
    npm run dev
    ```

**Важно**: Перед первым запуском убедитесь, что все зависимости установлены:
```bash
composer install
npm install
```

## 6. Процесс Развертывания (Deploy)
Проект настроен для работы в стандартном окружении PHP/Laravel:
1.  Установка зависимостей: `composer install`, `npm install`.
2.  Сборка фронтенда: `npm run build`.
3.  Миграции БД: `php artisan migrate`.
4.  Кеширование конфигурации: `php artisan config:cache`, `php artisan route:cache`.

## 6. Рекомендации по Развитию
*   **API**: При росте функционала рекомендуется вынести API маршруты в `routes/api.php`.
*   **Тесты**: Расширить покрытие тестами (сейчас есть базовая конфигурация PHPUnit/Pest).
*   **Локализация**: Если планируется мульти-язычность, использовать стандартные механизмы Laravel Localization.
